# S01.3 — Ticket waves and scaffolds

## What to build

`bun loom task:plan <owner>` prints the owner's tickets grouped into waves that can run in
parallel. `bun loom task:new` writes an owner (flow, plan, design pack scaffold) or a ticket
(`depends_on` from `--depends-on`) depending on whether the parent id exists.

## Acceptance criteria

- Waves group tickets whose dependencies are all in earlier waves.
- `task:new S12 "…"` writes the flow section and `docs/design/S12/` documents with the required
  headings; `task:new S12.1 "…" --depends-on S12.2` writes a draft ticket with `depends_on`.
- Both scaffolds pass the task gate as written.
