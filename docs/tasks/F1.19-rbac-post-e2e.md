# F1.19 — Pembuktian RBAC end-to-end (entitas uji `post`)

## Catatan penting

Kode `post` TIDAK ada di `master` — disimpan di branch `local/rbac-posts`
(perintah owner: uji post tidak boleh masuk template sampai GitHub).
`master` hanya mewarisi bagian umum: helper test grant/revoke izin, katalog izin
`post.*` di statements (contoh entitas ketiga), dan perbaikan `db.transaction`.

- Test RBAC 4 kasus: anonim 401, owner CRUD+audit, staff 403 semua aksi,
  role custom ber-izin `post.read` saja (revoke -> 403, grant -> 200 langsung).
- Web halaman `/posts` dengan nav difilter izin.
