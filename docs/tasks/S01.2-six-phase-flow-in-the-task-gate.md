# S01.2 — Six-phase flow in the task gate

## What to build

The task gate requires a `## Flow` section in every owner task, enforces phase order and notes,
blocks tickets and checkpoints until the owner's design phase is ticked, validates the design
pack, and lets a draft ticket depend on another draft ticket.

## Acceptance criteria

- An owner without the six phases, or with a phase ticked out of order or without a note, fails.
- A started ticket or a ticked checkpoint before design is ticked fails.
- A ticked design phase without a complete `docs/design/<owner>/` pack fails, naming the missing
  file or heading.
- A ticked plan phase needs a `## Plan` section and at least one checkpoint per ticket.
- A ticked execute phase needs every checkpoint ticked; `ready`/`done` need all six phases.
- A draft task may depend on a draft task; a started task may not; a cycle fails.
