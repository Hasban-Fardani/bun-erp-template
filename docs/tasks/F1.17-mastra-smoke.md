# F1.17 — Smoke test Mastra x Bun

## Result

Settled in ADR-0012: Mastra 1.68.0 runs on Bun 1.4.2, and is **not** adopted into the
template. The decision and its reasoning live in that ADR; this file records the evidence.

## Evidence (agent, awaiting human verification)

Run on Bun 1.4.2 against `@mastra/core` 1.68.0, in a throwaway directory (`/tmp`), never
inside this repo:

## Trap for anyone repeating this

A hand-written model stub makes streaming look broken. The stub must emit `text-delta`
parts whose payload field is `delta`; a stub using `textDelta` silently produces an empty
stream and looks like a Bun incompatibility. Use `createMockModel` from
`@mastra/core/test-utils/llm-mock` instead — it is what turned the false negative into a
pass.

## Reproducing

```bash
mkdir /tmp/mastra-spike && cd /tmp/mastra-spike
bun init -y && bun add @mastra/core && bun add -d vitest
```

The `vitest` dev dependency is required: Mastra's own mock helper imports it.

Then drive an `Agent` with `createMockModel({ mockText: "pong" })` and assert on
`generate().text` and the fully consumed `stream().textStream`.
