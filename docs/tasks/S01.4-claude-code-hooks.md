# S01.4 — Claude Code hooks

## What to build

A tracked `.claude/settings.json` runs a SessionStart hook that restores missing skills (asking
Claude Code to reload them) and states the flow, and a UserPromptSubmit hook that names each
active owner's next phase. `.diagram-design` selects the default diagram profile.

## Acceptance criteria

- The session hook prints valid SessionStart JSON with `reloadSkills` only when it installed
  something, and never fails the session when the install fails.
- The prompt hook names the next unticked phase of each in-progress owner and what that phase
  requires.
