## Scope

Owner requested Hono best-practice review, a developer file map, generated web pages,
separate mobile React source and mandatory atomic design. Existing business behavior remains
covered by API/browser tests. Native authentication/device validation are outside this scaffold.

## Implementation

Bun bootstrap, context types, HTTP middleware/error handling and Variables have separate owners.
Typed route chains and domain services follow Hono guidance. Middleware covers API and docs.
Web Vite generates route wrappers from pages, with authentication in a pathless layout; screen
implementations live under web features. Automatic code splitting separates screen bundles.
Mobile owns entry/pages/Vite; both apps import atomic UI. ResourceTable accepts a controller,
not web hooks. Architecture, UI, copy, surface, design and React checks cover moved/new source.
The scope manifest permits the authorized packages workspace; generated route tree alone is
excluded from lint/narrative rules. Gate rules are retained, with discovery paths updated.
