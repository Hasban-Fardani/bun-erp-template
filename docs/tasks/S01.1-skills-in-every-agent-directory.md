# S01.1 — Skills in every agent directory

## What to build

The skill installer writes every required skill into `.agents/skills` and `.claude/skills`, the
agents gate reports a missing copy in either directory, and `bun loom ai:skills` restores them
without the rest of `ai:update`.

## Acceptance criteria

- A skill present only in `.agents/skills` is reported missing for `.claude/skills`.
- The installer passes both agents to the skills CLI and re-installs a skill missing from either
  directory.
- `.claude/skills/` is ignored by Git like `.agents/skills/`.
